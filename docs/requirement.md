## Requirements
    - The program shall allow the user to enter classroom temperature readings in 
    Fahrenheit.
    - The program shall determine whether the temperature is between the acceptable range of 68F - 76F, inclusive.
    - The program shall display an appropriate NORMAL or WARNING status.
    - The pogram shall calculate the recorded temperatures.
    - The program shall use C language.
    - The program shall save the temaperature readings and their statuses to a file.
    - The program shall use an LED connected to the Raspberry Pi to indicate a warning condition.
    - The program shall allow the acceptable temperature range to be changed according to a new client.
